Nuestro proyecto insignia

HydroLeaf Pro

HydroLeaf Pro es nuestro sistema de monitoreo automatizado para cultivos hidropónicos DWC (Deep Water Culture). Desarrollado integramente por el equipo Verdanta, combina un microcontrolador ESP32, sensores de pH, temperatura (4× DS18B20), nivel de agua (HC-SR04) y una pantalla LCD, todo gestionado desde una interfaz web alojada localmente. Este proyecto nació en el CETI Plantel Río Santiago como solución real a los retos del cultivo controlado en México.

1. Privacidad de Datos y Seguridad

El sitio web de Verdanta AgriTech implementa las siguientes medidas de seguridad para proteger los datos de sus usuarios:

🛡️ Base de datos — Supabase

La base de datos está alojada en Supabase (PostgreSQL), una plataforma que implementa cifrado en tránsito (TLS/HTTPS) y en reposo. El acceso a los datos está controlado mediante Row Level Security (RLS), que define políticas de lectura y escritura por tabla. Las credenciales de la BD nunca se exponen al usuario final — solo se utiliza la clave pública anon key que tiene permisos limitados.

🔑 Autenticación — Supabase Auth

El sistema de inicio de sesión utiliza Supabase Auth, que maneja el almacenamiento de contraseñas con hashing seguro (bcrypt). Las sesiones se gestionan mediante tokens JWT con expiración automática. Las contraseñas nunca se almacenan en texto plano ni se transmiten sin cifrado.

🌐 Transporte seguro — HTTPS

El sitio está servido exclusivamente mediante HTTPS a través de GitHub Pages, que incluye certificados SSL/TLS automáticos. Toda comunicación entre el navegador del usuario y el servidor está cifrada, previniendo ataques de tipo man-in-the-middle.

📋 Datos recolectados

El sitio recolecta únicamente: correo electrónico y contraseña (para autenticación) y respuestas de la encuesta de satisfacción (sensores, comentarios). No se recopilan datos de geolocalización, cookies de rastreo, ni información financiera. No se comparten datos con terceros.

La identidad de marca de Verdanta AgriTech surgió a partir de una clase de Emprendimiento, en la que se trabajaron fundamentos de branding: selección de paleta de colores, tipografía, valores de marca y posicionamiento. Diseño del sitio web

El diseño visual del sitio web fue creado de manera original por Bania Natalia Luna Pazos con asistencia de inteligencia artificial (Claude de Anthropic). La paleta de colores (verde oscuro #0D1A12, verde medio #1A5C36 y verde brillante #3DDC6E) fue seleccionada para evocar naturaleza, tecnología y crecimiento, en línea con el giro agrícola de la empresa. Logotipo de la marca

El logotipo de Verdanta AgriTech consiste en la letra "V" estilizada en la tipografía Cormorant Garamond acompañada del nombre completo "Verdanta". Fue diseñado con asistencia de inteligencia artificial y desarrollado por la alumna Bania Natalia Luna Pazos. El concepto visual refleja el nombre de la marca, derivado del latín viridis (verde), en alusión a la agricultura sostenible.
